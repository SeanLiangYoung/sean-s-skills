# Templates — Skill 与能力模板

本目录存放创建新 Skill 或能力时使用的模板文件。

## 来源

- **SKILL-template.md**：来自 [anthropics/skills](https://github.com/anthropics/skills) 的 `template/SKILL.md`，符合 [Agent Skills 规范](../spec/specification.md) 的最小 frontmatter + 正文模板。

## 使用方式

复制 `SKILL-template.md` 到新 Skill 目录下并重命名为 `SKILL.md`，按规范填写 `name`、`description` 及正文说明。
