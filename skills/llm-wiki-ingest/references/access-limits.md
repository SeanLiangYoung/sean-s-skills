# 访问限制与补充资料

访问成功不仅看 HTTP 状态：200 页面也可能只含登录页、付费提示、验证码、空壳或预览。检查能否读取目标正文、附件和关键媒体。403 不自动意味着付费墙；无法确定原因时报告已观察的现象，不猜测。

区分：需要登录或付费、权限拒绝、地区或反爬限制（仅在有证据时确认）、429 限流、404/删除、超时或临时故障、JavaScript 正文不可见，以及正文可读但图片/视频不可读。超时最多再试一次；可用时尝试一次合适的正常浏览/正文读取方式，仍受限就停止，不循环尝试，不绕过验证码、登录、权限或付费限制。

有用户已提供的正文或本地副本时，继续分析该版本，说明原链接未核验。没有完整材料，或缺失媒体影响核心分析时，及时向用户请求补充资料，同时继续处理其他可读来源：

> 这个链接目前返回［实际状态或提示］，我能读取［范围］，但缺少［正文/图片/视频等］。请提供［最少且合适的补充：复制正文、导出的 PDF/HTML、本地文件、关键截图、音视频附件或带时间戳的转录稿］。我会先整理已能读取的部分，缺失部分暂不作结论。

涉及多个受限地址时一次列出地址、状态、已读范围与需要补充的内容，避免反复逐条询问。不要要求用户提供密码、Cookie、令牌；由用户自行正常打开并导出资料。请求附件或截图应使用正常聊天消息，不能用仅支持文本的异步问题工具。

完全未读到来源时只保留来源线索与待补充状态，不能建立似乎已验证的知识结论；部分可读时将其标为部分读取。入库记录及最终回复都注明限制，不因保存成功而隐去缺失。收到补充后复用已有来源页，补全证据、修正暂定结论并更新日志。
