# Tools — 营销/分析工具注册与集成说明

本目录为 **AI 可发现的工具能力索引与集成指南**，便于 Agent 在营销、分析、SEO 等场景下选用第三方服务与 API。

## 来源

来自 [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) 的 `tools/`：
- **REGISTRY.md**：工具索引（分类、API/MCP/CLI/SDK 支持、集成文档链接）。
- **integrations/**：各工具的详细集成说明（约 50+ 个 .md），涵盖 Analytics、SEO、Email、Ads、CRM 等。

## 使用方式

1. 按 REGISTRY.md 查找工具与能力。
2. 按 `integrations/<tool>.md` 查阅具体集成步骤与常用操作。
